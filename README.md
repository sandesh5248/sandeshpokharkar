# Personal Portfolio

This is a modern, responsive personal portfolio website built with:

- **React** (Vite)
- **Framer Motion** for animations
- **Lucide React** for icons
- **Vanilla CSS** with variables for consistent theming

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Customization

- Update `src/pages/Home.jsx` to change content.
- Update `src/index.css` to change colors/theme.
